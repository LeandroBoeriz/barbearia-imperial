# Barbearia Imperial

Site fictício de uma barbearia, desenvolvido para praticar HTML5 e CSS3.

## Sobre o projeto

A Barbearia Imperial é uma página institucional que apresenta os serviços, preços e informações de contato de uma barbearia.

## Tecnologias utilizadas

- HTML5 — estrutura e organização do conteúdo.
- CSS3 — estilização e identidade visual.
- Flexbox — organização dos elementos.
- Media Queries — adaptação para diferentes tamanhos de tela.

## Funcionalidades

- Menu de navegação entre seções.
- Apresentação dos serviços e preços.
- Layout responsivo.
- Botão de agendamento.
- Link para WhatsApp com número demonstrativo.
